# ConfigScope

Нативное Windows-приложение для просмотра изменений конфигураций 1С в Git. Оно показывает историю на языке объектов 1С и даёт двустороннее построчное сравнение BSL/XML.

## Возможности версии 0.3.2

- единый desktop-интерфейс ConfigScope с разделами обзора, изменений, качества, проектов и обновлений;
- трёхпанельная работа: коммиты → изменённые файлы → сравнение;
- фильтры «Код», «XML» и «Все»: по умолчанию технические XML-файлы скрыты;
- адаптивный diff: новые и удалённые файлы открываются на всю ширину, обычные изменения — рядом;
- перенос длинных строк и ручное переключение между автоматическим и раздельным режимом;
- распознавание основных типов метаданных 1С;
- автоматические предупреждения для `.orig`, `.bin`, изменений прав и конфликтных маркеров;
- подключение нескольких локальных Git-репозиториев;
- поддержка GitHub, Gitea и обычных Git-серверов через локальную копию репозитория;
- корректный анализ merge-коммитов относительно первого родителя;
- группировка файлов коммита по объектам 1С;
- ручная синхронизация `git fetch` с отображением расхождения локальной и удалённой веток;
- чтение актуальной удалённой ветки после синхронизации без изменения рабочей копии;
- предупреждения о крупных изменениях с учётом количества затронутых строк;
- автоматическая загрузка и тихая установка новых версий из GitHub Releases;
- обязательная проверка SHA-256 перед запуском установщика;
- Windows-пакеты с контрольной суммой SHA-256.

## Запуск

Рекомендуемый вариант — скачать `ConfigScope-Setup-*.exe` из GitHub Releases и пройти обычную установку. Установщик работает без прав администратора, добавляет приложение в меню «Пуск» и поддерживает стандартное удаление через Windows.

Портативная ZIP-сборка также остаётся доступной. При первом запуске приложение предложит выбрать локальный Git-репозиторий с выгрузкой конфигурации.

```powershell
dotnet run --project src/OneCChangeMonitor.Desktop
```

Пользовательские настройки хранятся в `%LocalAppData%\OneCChangeMonitor\settings.json`, а диагностические журналы — в `%LocalAppData%\OneCChangeMonitor\logs`. Приложение не отправляет содержимое конфигурации на внешние серверы. Сеть используется только для Git и необязательной проверки GitHub Releases.

## Архитектура

- `Domain` — модели предметной области;
- `Application` — сценарии, контракты и разбор unified diff;
- `Infrastructure` — Git CLI и классификация путей 1С;
- `Desktop` — основное WPF-приложение Windows;
- `Web` — вспомогательный HTTP-режим;
- `Tests` — автоматические тесты.

План развития находится в [docs/roadmap.md](docs/roadmap.md).

## Изменения 0.3.1

- исправлено отображение файлов и diff для merge-коммитов;
- после `git fetch` история читается из `origin/<ветка>`, если удалённая ветка доступна;
- в интерфейсе показывается состояние синхронизации ветки;
- изменения сгруппированы по объектам конфигурации;
- предупреждения для `.orig`, бинарных файлов и прав объединяются по объектам;
- добавлены интеграционные тесты Git для merge и отстающей локальной ветки.

## Изменения 0.3.2

- обновление устанавливается непосредственно из интерфейса без перехода в браузер;
- приложение загружает установщик и опубликованную контрольную сумму;
- перед установкой SHA-256 проверяется криптографически;
- повреждённый или подменённый файл не запускается;
- установка выполняется в тихом режиме, после чего ConfigScope запускается снова.
