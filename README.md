# OneC Change Monitor

Windows-приложение для просмотра изменений конфигураций 1С в Git. Оно показывает коммиты, распознаёт объекты 1С по структуре выгрузки и отображает построчный diff BSL/XML.

## Возможности версии 0.1

- подключение нескольких локальных Git-репозиториев через конфигурацию;
- выбор репозитория и ветки;
- просмотр истории коммитов;
- распознавание основных типов метаданных 1С;
- список изменённых файлов и объектов;
- построчный diff кода и XML;
- предупреждения для `.orig` и `.bin`;
- ручная синхронизация `git fetch`.

## Запуск desktop-версии

Скачайте Windows-сборку из GitHub Releases или артефактов последней успешной сборки и запустите `OneCChangeMonitor.exe`. При первом запуске приложение предложит выбрать папку локального Git-репозитория конфигурации 1С.

Программа не открывает консоль и браузер. Пользовательские настройки хранятся локально в `%LocalAppData%\OneCChangeMonitor\settings.json`.

## Запуск из исходников

Для desktop-приложения:

```powershell
dotnet run --project src/OneCChangeMonitor.Desktop
```

Веб-интерфейс оставлен как вспомогательный режим для будущего серверного развёртывания:

```powershell
dotnet run --project src/OneCChangeMonitor.Web
```

## Архитектура

- `Domain` — модели предметной области;
- `Application` — сценарии и контракты;
- `Infrastructure` — Git CLI и классификация путей 1С;
- `Desktop` — основное нативное WPF-приложение Windows;
- `Web` — вспомогательный HTTP API и веб-интерфейс;
- `Tests` — автоматические тесты.

Дальнейшие этапы: PostgreSQL, webhook Gitea, семантический XML-diff, история объектов, GitHub Releases и безопасное автообновление.
