# Дорожная карта OneC Change Monitor

## 0.2 — Product shell

- новый Windows-интерфейс и навигация;
- side-by-side diff BSL/XML;
- несколько локальных проектов;
- первичные проверки качества;
- проверка GitHub Releases и контрольные суммы Windows-пакетов.

## 0.3.0 — Интерфейс ConfigScope

- единый Windows-интерфейс и навигация;
- трёхпанельный просмотр коммитов, файлов и diff;
- несколько локальных проектов;
- первичные проверки качества;
- проверка GitHub Releases и контрольные суммы Windows-пакетов.

## 0.3.1 — Gitea и надёжность Git

- анализ merge-коммитов относительно первого родителя;
- актуальная история `origin/<ветка>` после `git fetch`;
- состояние локальной и удалённой веток;
- группировка файлов по объектам 1С;
- усиленные проверки `.orig`, бинарных файлов, прав и крупных изменений;
- интеграционные тесты на реальных Git-сценариях.

## 0.3.2 — Автоматические обновления

- загрузка установщика из GitHub Releases внутри приложения;
- проверка опубликованной SHA-256 перед запуском;
- тихая установка без ручного скачивания;
- автоматический повторный запуск ConfigScope после обновления.

## 0.3.3 — Дерево изменений

- иерархия источника, типа метаданных, объекта, компонента и файла;
- фильтрация кода и XML с сохранением родительского контекста;
- поиск по объекту, компоненту и пути;
- сводка статистики строк и риска для выбранного узла.

## 0.3.4 — Объекты и персональная лента

- отдельный каталог объектов текущей конфигурации 1С;
- компоненты и Git-история выбранного объекта;
- сворачиваемая основная навигация;
- скрытие сторонних и служебных коммитов с указанием причины;
- автоматическое распознавание выгрузок в `src` и `src/cf`.

## 0.3.5 — Исправление запуска

- исправлена загрузка WPF-интерфейса с контекстным меню коммитов;
- добавлена проверенная демонстрация интерфейса на обезличенном проекте.

## 0.4 — Семантика 1С

- семантическое сравнение XML вместо показа технических строк;
- события «добавлен реквизит», «изменена форма», «изменено право»;
- полная история выбранного объекта;
- фильтры по типу объекта, автору и виду изменения.

## 0.5 — Релизы и отчёты

- сравнение веток и тегов;
- состав релиза, сгруппированный по объектам 1С;
- формирование заметок к выпуску;
- экспорт отчёта о выпуске;

## 0.6 — Контур качества

- расширяемые правила проверки BSL/XML;
- интеграция с BSL Language Server;
- подпись Windows-пакетов и откат при неуспешном обновлении.

## Дальнейшее развитие

- граф зависимостей объектов конфигурации;
- адаптеры GitHub, Gitea и других Git-серверов;
- уведомления и командные обзоры изменений;
- отдельное расширение 1С для аудита изменений данных информационной базы.

Аудит данных отделён от анализа Git: он требует собственного источника событий на стороне 1С и не должен смешиваться с историей исходного кода.
