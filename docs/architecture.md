# Архитектура

Проект строится как модульный монолит. Git остаётся источником истины, а приложение формирует индекс для быстрого поиска и анализа.

## Поток данных

`Gitea webhook → Git fetch → анализ коммита → классификация объектов 1С → хранилище → Web API → интерфейс`

В версии 0.1 история читается непосредственно из локальной копии Git. Постоянный индекс и очередь фоновых заданий будут добавлены после проверки модели данных.

## Несколько репозиториев

Все операции имеют `projectId`. Настройки путей выгрузки принадлежат проекту, поэтому одна установка сможет анализировать разные конфигурации и разные структуры каталогов.

## Обновления приложения

Планируемая схема: тег GitHub → GitHub Actions → GitHub Release → проверка версии → резервная копия → установка → проверка состояния → откат при ошибке. Автоматическая установка по умолчанию выключена.
